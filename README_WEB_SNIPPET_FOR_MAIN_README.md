## Official Web Interface — Flask / JavaScript

The project now includes a professional Flask / JavaScript dashboard as the official web interface.

Run:

```bash
python src/web/app.py
```

Open:

```text
http://localhost:5000
```

The dashboard reads from MongoDB and includes:

- pipeline status,
- sentiment analytics,
- score analytics,
- prediction results by review date,
- ProductId `B001E4KFG0` analysis,
- model quality analytics,
- confusion matrix,
- streaming micro-batch operations,
- risk monitoring,
- latest prediction events,
- PDF report export.

Streamlit can remain as a bonus prototype, while Flask is the official project web dashboard.
